# PROBEATS — Maquette e-commerce

Projet réalisé dans le cadre de ma formation de Développeur Web Full-Stack.

## Présentation

PROBEATS est une marque fictive de matériel audio proposant une expérience sonore Ultra-Haute-Qualité.

L'objectif de ce projet était de réaliser sur Figma la maquette desktop du futur site e-commerce de la marque.

## Pages réalisées

- Accueil
- Produit
- Commande
- À propos
- Assistance
